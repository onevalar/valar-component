# 动效与交互反馈

> 本规范由 Valar 维护者定稿，用于约束动效节奏、交互反馈与加载呈现；后续调整须经维护者确认，AI 不得擅自改写。

## 动效基调

- **极简克制、服务于功能**：以组件自带默认动效为主，只做短促利落的状态过渡（`100–200ms`），不做炫技弹跳或无意义的位移。
- **只用全局动效档位**：优先保留组件默认动效；确需显式添加过渡时，必须使用全局档位（`duration-fast` / `duration-interaction` / `duration-normal` / `duration-slow`）和全局曲线（`ease-enter` / `ease-exit` / `ease-standard`），严禁手写随意毫秒数和自定义曲线。
- **尊重减少动态效果**：遵循系统 `prefers-reduced-motion` 偏好，开启后关闭非必要位移与缩放动画。

## 明确禁止的装饰性动画

- 严禁首屏或列表加载时做“逐行飞入 / 交错淡入”（stagger）装饰动画，内容应立刻可读。
- 严禁给普通卡片或列表行加“悬停上浮 / 放大”效果，悬停仅以轻微底色或描边变化表达。
- 严禁给高频切换（如标签页内容切换、快捷键响应）加拖沓的慢过渡。

## 操作结果反馈（就地优先，克制 Toast）

- **字段校验**：错误直接显示在对应字段下方，不额外弹 Toast。
- **即时操作**：开关切换、复选勾选、轻量排序等直接即时生效，不弹多余提示。
- **Toast 仅用于必要场景**：只有跨区域结果反馈（如“已复制”“已删除”）或后台异步失败时，才弹出轻量 Toast。

## 加载与等待状态

- **局部优先、不锁整页**：内容加载优先使用与真实结构等高的骨架屏（`Skeleton`）。
- **按钮原地反馈**：提交或执行中在按钮原地禁用并显示内置微加载图标（`Spinner`）。
- **禁用无必要全屏遮罩**：除非阻断性初始化，否则严禁弹全屏遮罩转圈。
