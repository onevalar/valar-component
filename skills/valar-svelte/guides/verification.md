# 独立视觉与合规验收

> 遵循“单 Agent 一气呵成创作 + 独立黑盒验收”原则：界面编写完成后，必须先跑机器规则检查，再从用户视角在真实浏览器里逐项黑盒自检，发现问题先自修再交付。

## 1. 机器硬验收（必须零 error）

运行 `pnpm exec valar-svelte lint`，确保无报错并审阅全部 warning，重点确认没有触发：

- 语义颜色、像素任意值、动效档位、表单标签、弹层标题与触发器嵌套问题；
- 反 AI 味审美拦截：`valar/no-nested-card`（卡片套卡片）、`valar/no-accent-side-border`（圆角单侧高亮边）、`valar/no-hover-lift`（悬停上浮/放大）、`valar/no-redundant-placeholder`（“请输入…”废话占位符）、`valar/single-primary-action`（同操作区多个主按钮）。

## 2. 真实浏览器黑盒视觉核查

在开发预览中至少核查 **桌面宽屏（浅色 + 深色）** 与 **窄屏（390px）** 三个视图，逐条打勾：

1. **层级与留白**：主要靠留白间距区分分组，无套娃卡片、无多余框线与单侧彩边，设置/表单页收窄居中，列表/表格页撑满工作区。
2. **主次焦点**：每个视区与弹窗最多 1 个主色强调按钮；页头主按钮在右，弹窗/表单底部「取消在左、主操作在右」。
3. **文案克制**：无多余副标题和底部解释卡；占位符为格式示例；无营销感叹号与滥用 Emoji；危险确认写明具体动作对象。
4. **数字与表格**：计数、金额、百分比与时间均等宽对齐（`tabular-nums`）；宽表格在窄屏仅容器内横向滚动，不撑破整页。
5. **交互与状态**：空态、加载态（骨架屏 / 按钮内 Spinner）、报错态齐全；键盘 Tab 焦点清晰且绘制在组件边界内；悬停无上浮跳动。
6. **无裁切遮挡**：长标题、标签和按钮在窄屏与浮层中不重叠、不溢出、不被父容器错误裁切。
