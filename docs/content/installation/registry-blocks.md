## Install a Svelte block

This inventory covers 78 entries in the Valar block preview index. The six [shared business scenes](/docs/ai-elements) are documented separately; chart-gallery examples outside the block preview index are not listed here.

1. Follow the [Svelte installation guide](/docs/installation) to prepare your Svelte 5 / Tailwind CSS 4 app, start the local Valar registry, and initialize `components.json`.
2. Open the linked name in the **Svelte install name and preview** column. From the Valar repository root, run the command below, replacing `BLOCK_ID` with that exact name.

```sh
pnpm --filter @valar/svelte-cli start add BLOCK_ID --cwd /absolute/path/to/your-app
```

The CLI copies the block and its registry dependencies. Check `/registry/styles/valar/BLOCK_ID.json` on the docs site (or the matching file under `docs/static/`) for file targets and declared dependencies. Single-file demos go to the configured components directory; page blocks with `registry:page` files go to `src/routes` on SvelteKit. In other Svelte apps, page files go to the components directory; mount them in your own routing. Alternate blocks can share filenames such as `app-sidebar.svelte` or `login-form.svelte`; review the CLI's overwrite prompts before combining variants. Replace demo routes, sample data, and document-root assets such as `/placeholder.svg` and `/favicon.svg` as needed.

**React and Vue links open a native preview, copyable source, and local package setup for the block.** The behavior column describes the Svelte source; native templates use their own framework APIs and fixtures rather than promising pixel-for-pixel equivalence. The Svelte CLI does not install React or Vue code.
