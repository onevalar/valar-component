# Color Picker 设计规范

- 用于让用户选择任意颜色的数据（标签色、品牌色、主题编辑）；只在少数固定颜色间选择时用 Radio Group。界面本身的颜色仍然只用语义 token，不要把 Color Picker 选出的值写进组件样式。
- `label` 必填，供触发按钮和预设组识别。通用模式显示该标签；标签行的紧凑模式把标签留给辅助技术，并让相邻文字标识业务标签。
- 值始终是小写的六位十六进制（`#rrggbb`）；三位简写会被展开，无效输入不会改变值。需要其他格式时在使用处自行转换。
- 常用颜色放在 `presets`；放在表单中提交时设 `name`。
- 标签行使用 `appearance="label"`。触发器 25 px，当前色点 9 px，预设按钮 22 px。预设增加命名时使用 `{ color, label }`。预设面板以 16 px 排列，在窄屏中换行。自定义区域支持方向键和指针，Hex 用 Enter 确认，Escape 返回触发器。
- 面板使用悬浮 Scroll Area 处理受限高度。所有键盘反馈画在控件内部。
