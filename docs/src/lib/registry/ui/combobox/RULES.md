# Combobox 设计规范

- 需要搜索再选择时用 Combobox。少量固定选项用 Select，搜索后执行操作用 Command。
- 提供 `label` 和搜索 `placeholder`。选项使用稳定且唯一的 `id`，额外搜索词放在 `keywords`。
- 单选确认后关闭并归焦，复选保持打开。已选值以勾选和 `aria-selected` 表达，方向键仅移动高亮。允许清空单选时提供明确的「未分配」选项。
- 默认浮层 207 px，浅深表面、细边框和阴影沿用工作区浮层。搜索行高 36 px、左边距 14 px，不放搜索图标。候选至少 32 px 高，状态高亮使用内收的圆角底色。
- 可用 `group` 分组，用 `option` 传入头像或状态图标。行尾留给当前选择。长选项允许换行，列表独立滚动。
- 异步筛选用 `bind:query` 并传 `filter={false}`，由宿主取消或丢弃过期查询。使用 `loading`、`error`、`empty` 表达等待、错误和无匹配；可将重试等操作放在 `footer`。
