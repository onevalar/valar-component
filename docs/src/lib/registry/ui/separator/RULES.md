# Separator 设计规范

- 方向用 `orientation`（默认横向）；竖向分隔需要父元素有高度或在 flex 行中使用。
- 只起视觉分隔作用时设 `decorative`，读屏器会忽略它；分隔两段有意义的内容时保持默认。
- 默认粗细 0.5 px。设置卡片行间线浅色用黑色 8.8%，深色用白色 8.3%，随卡片表面合成。卡片有 16 px 行内留白时，行间线可以和内容对齐。
- 用同一粗细与颜色分隔竖向内容。需要局部主题色时，在容器上设置 `--valar-separator`。带文字的分隔在对话中用 `<Marker.Root variant="separator">`。
