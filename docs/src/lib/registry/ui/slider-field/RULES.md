# Slider Field 设计规范

- 用于有明确范围、需要查看或精确输入数值的参数，例如尺寸、透明度和主题对比度。无需显示数字时用 Slider，没有范围的数字用 Number Field。
- `label` 必填。默认外观用它命名滑块、数字输入框和加减按钮。读数外观将可见标签与滑块关联。
- `appearance="readout"` 用于设置项。控制组宽 250 px、高 32 px，读数与滑块一起换行。读数不参与 Tab 轮转，焦点提示保留在滑块内侧。
- 单位写在 `unit`（如 `unit="px"`），它只显示在数字后面，不进入值；值始终是数字。
- 必须给出 `min`、`max`、`step`。超出范围或无法解析的输入会被标为无效并保持上一个有效值，不要另外写截断逻辑。
- 放在表单中提交时设 `name`，提交的是纯数字。
