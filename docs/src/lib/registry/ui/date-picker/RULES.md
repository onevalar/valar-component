# Date Picker 设计规范

- 用于输入或选择一个日期或计划周期。选两个确定的日期时可组合两个 Date Picker，连续选择一段日期时用 Range Calendar。
- 用 `bind:value` 绑定日期，或者用 `value` 和 `onValueChange` 接入宿主。值包含 ISO 日期和精度，非日精度的日期为该周期第一天。
- 提供清楚的 `label`。用 `precisions` 限制允许的精度，只有具体日期的场景用 `["day"]`。
- 用 `min` 和 `max` 约束可选范围。月份、季度等按周期与范围是否相交判断。
- 打开后聚焦日期输入。可直接输入 ISO 日期、英文月份和年份、季度、半年或年份，按 Enter 提交。组件按输入格式识别精度，并校验允许的范围。已有日期且允许清除时，可按「清除日期」或清空输入后按 Enter。
- 无效或超出范围时在输入下方说明并保留焦点。日期可通过键盘选择，Escape 关闭并返回触发器。
- 在有独立主题的区域传入 `portalProps` 继承该主题。焦点提示画在控件内部。
