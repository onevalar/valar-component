# Issue Detail

用于从问题列表打开并编辑一个工作项。标题与描述共用一份编辑草稿。保存或 Cmd/Ctrl+Enter 提交，取消或 Escape 放弃内容草稿。属性选择即时提交，宿主通过 onUpdate 合并局部更新。

- 宽容器在右侧展示属性、标签和项目。窄容器把同一批控件排到标题下方，保持键盘操作和可访问名称。
- 只读描述使用结构化富文本；旧数据可以直接传入纯文本。编辑器保存时同时给出结构化内容及纯文本。
- 由宿主提供负责人、项目和标签选项，以及保存和返回行为。预览状态仅保存在当前页面。
- 嵌入有自己标题栏的区域时，使用 `embedded` 隐藏详情的边框与默认标题栏。宿主负责提供标题栏和返回入口。

- 传入 `activity` 显示活动、评论与一级线程。宿主持有按时间排列的条目，通过 `onAction` 处理操作，按问题 ID 保存状态。
- 评论编辑权限由作者 ID 决定。发布或保存支持 Cmd/Ctrl+Enter。取消有改动的草稿时先确认，放弃或保存后焦点回到评论菜单。
- 评论草稿和问题标题／描述使用独立表单。回车可在评论中换行，提交只作用于当前表单。

- 传入 `activity.collaboration` 后，活动标题同行显示订阅与订阅者头像，问题、评论和回复分别保存各自的回应。回应按钮用 `aria-pressed` 表示当前用户的状态，移除最后一个回应时把焦点还给添加回应入口。
- 解决线程后折叠为可展开的摘要，解决状态保存在宿主，展开状态属于当前界面。摘要保留条数、作者和选中的结论。重新打开后恢复评论、回应及回复入口。
