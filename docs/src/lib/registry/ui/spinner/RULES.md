# Spinner 设计规范

- 用于无法估计进度的短暂等待；可以计算进度时用 Progress，内容区域加载用 Skeleton。
- 图标 Spinner 自带 `role="status"`，默认读屏名称是“加载中”。能说明具体在做什么时传更具体的 `aria-label`（如“正在保存”）。
- 行内同步反馈可用 `appearance="dots"`，用 `label` 提供状态文字。保持 24 px 行高与三个点的固定占位，三点按约 1 秒周期错峰；开启减少动态效果时静态完整显示。消息由外层状态区域播报时，为内层 Spinner 传 `role="none"`。
- 放在按钮中表示提交中时，同时禁用按钮并保留按钮文字（“保存中…”），不要只换成 Spinner。
- 尺寸用 `size-*` 档位类，颜色继承文字颜色，不要单独设色。
