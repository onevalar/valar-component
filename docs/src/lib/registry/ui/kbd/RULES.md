# Kbd 设计规范

- 只用于显示键盘按键或快捷键；组合键用 `Kbd.Group` 包住多个 `Kbd`，不要写成一整段文字。
- 显示的快捷键必须真正可用；区分平台时按 macOS（⌘、⌥）和其他系统（Ctrl、Alt）分别显示。
- 默认键帽参考 Linear 快捷键面板。高 21 px、最小宽度 20 px、水平留白 4 px、圆角 3 px，组合键间隔 3 px。透明底，浅深主题使用各自的文字和细描边。
- 菜单项尾部使用 `appearance="inline"`，字号 11 px，行高 12.1 px，字重 500。没有描边和内边距。
- 工作区工具提示使用 `Tooltip.Hint`，内置 `appearance="compact"` 键帽。高 17.1 px、最小宽度 18 px、圆角 4 px、水平留白 2 px，字重 400。
- 键帽是静态提示，随相邻的动作说明一起展示。通过带标签的动作响应按键，键帽本身无需获取焦点。
