# Issue Composer

用于从问题列表、空状态或全局入口创建问题。标题和描述纵向排列，状态与优先级放在编辑区下方。底部左侧添加附件，右侧依次放置继续创建开关和主操作。紧凑和展开模式使用同一份草稿。

- 打开时聚焦标题。关闭后通过 `returnFocus` 回到触发器。切换大小时保持表单值和焦点所在的控件。
- 状态和优先级菜单支持搜索、方向键、Enter、数字快捷键与 Escape。输入搜索词时，数字用于搜索。
- 保留空白表单的提交入口。提交空标题时聚焦标题并读出错误。继续创建保留状态和优先级，并清空标题、描述与附件。
- 通过 `onCreate` 交付表单和本地文件。预览用多行纯文本描述，持久化和上传由宿主处理。
- 颜色、尺寸和动画作用于弹窗自身。窄屏保留 12 px 侧边间距，减少动态效果时取消尺寸过渡。
