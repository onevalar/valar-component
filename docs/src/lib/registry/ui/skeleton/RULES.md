# Skeleton 设计规范

- 用于加载时占位，形状和尺寸尽量与真实内容一致（文字行、头像、卡片），避免加载完成后布局跳动。
- 头像占位保留直径；同一行的文字占位随容器收缩，保留头像和文字之间的间距。
- 加载很快（几百毫秒内）时不要显示骨架屏；加载失败时替换为错误提示，不要一直显示 Skeleton。
- Skeleton 对读屏器没有意义：给加载中的容器设 `aria-busy="true"`，需要时另外放一段 `sr-only` 的“正在加载”文字。
- 颜色和动画跟随组件样式，不要另设背景色。
- 筛选条件生成期间用 `appearance="filter"`。占位高 24 px、圆角 8 px、间距 8 px，宽度由最终条件和可用空间决定。用 `delay` 指定毫秒级错峰。默认保留 1.2 秒入场和 2 秒循环，开启减少动态效果时立即显示静态占位。完成后在原位替换为条件，保留现有列表，并通过独立状态文字播报。
