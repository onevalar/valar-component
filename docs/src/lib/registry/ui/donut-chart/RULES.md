# Static Donut Design Rules

- Caller validates unique keys, finite nonnegative parts and a positive fixed total; the sum must not exceed that total.
- Never renormalize when hiding a legend row. Unallocated space represents the fixed denominator, not a new category.
- Decorative SVG: supply exact values and names in a nearby accessible legend.
- No minimum slice enlargement, animation, tooltips or hover resizing.
