# Badge 设计规范

- 用于状态、分类、计数等简短标记；用 `variant` 选择用途相符的样式。
- 已应用的问题标签用 `variant="label"`。胶囊高 24 px，左右留白 8 px，文字 12 px／450。可传入标签数据中的 `labelColor`，在 14 px 标记位内绘制 9 px 圆点，和文字相隔 6 px。浅深色沿用 My issues 实测值，描边为 0.5 CSS px，设备像素对齐由浏览器处理。
- 标签的描边色、文字色和底色过渡为 150 ms。开启系统的减少动态效果后即时切换。
- Badge 不是按钮：需要点击执行操作时用 `Button size="xs"` 等小号按钮；需要跳转时给 Badge 设 `href`，它会渲染为链接。
- 文字保持一两个词；用颜色表示状态时文字本身也要说明状态（“已失败”），不要只靠颜色。
