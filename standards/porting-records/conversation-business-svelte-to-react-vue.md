# 对话与业务组件：Svelte → React / Vue

2026-11-27 · 第 6 批 · 已实现并通过代表场景验收；完整转换仍待扩大验证。采用[转换规范 v1.0](../COMPONENT_PORTING.md)，基线 `cfd989c9f63156774dbfb3871cc1fa1774e62ee5`。以 `docs/src/lib/registry/ui/<slug>`、Svelte primitives、组件 RULES、业务区块调用方式和既有测试为准。MIT；Shiki 3.20.0、Tiptap core／pm／starter-kit 3.33.1 按两套 SDK 的来源文件登记，不使用 Svelte 运行时。React 19.2.3／Vue 3.5.45，Tailwind 4.3.3、Node 24.22.2、pnpm 12.14.0。未独立审阅。

| 来源组件 | 公共行为与目标方式 | 代表场景计划 |
| --- | --- | --- |
| Attachment | 状态、尺寸、媒体与动作组合。保留卡片整体触发与相邻命名按钮；宿主接管文件、取消和网络。 | 失败可读说明；取消动作不触发预览；键盘可操作，窄屏附件组内部滚动。 |
| Bubble | 消息气泡变体、内容、分组和异侧反应布局；宿主控制反应选择。 | 长文本不会挤出容器；核对分组、颜色和反应行。 |
| Code Block | 原生 `pre`／`code`、可聚焦滑动区、可选行号与换行、差异状态及复制确认。高亮为可选的懒加载增强；以文本节点而非 HTML 渲染 token。 | `<script>` 等显示为文本；窄屏切换换行；行号始点、差异标志及复制原始字符串；流式追加不重标记已完成行。 |
| Marker | 具名状态／活动标记，允许主机提供语义文字或装饰图标；不自动把装饰信息当通知。 | 标记变体和图标／说明在两主题与长内容下排版正确。 |
| Message | 稳定的消息布局、头／内容／附说明、头像与左／右对齐；不接管数据流。 | 用户和助手相邻，窄屏文本与附件的宽度约束。 |
| Message Scroller | 固定高度的原生可滚动区域；稳定消息 ID，按锚点进入新轮，读历史时不抢滚动；手动跳转与减少动效。 | 流式追加保持正在阅读位置；两次轮次锚点、滚回最新、失去目标及清理。 |
| Questionnaire | 独立进度、答案和错误；选择、可跳过、上一题、提交及焦点；宿主持有流程分支和网络。 | 不完整单选与文本错误、跳过、回退保留、选择多项、可观测提交及 SSR 初始题。 |
| Trace | 步骤、状态、可展开内容，复用 SDK Collapsible；宿主决定自动状态更新。 | 运行／失败／成功、键盘展开及可读状态，无仅 hover 的必要操作。 |
| Issue Composer | 模态、同一草稿、尺寸变化、标题校验、可搜索状态／优先级、本地附件、连续创建；通过回调交给宿主。 | 无标题错误聚焦，快捷键与筛选不混淆，关闭归焦，首次与后续创建载荷相互隔离。 |
| Issue Detail | 宿主持有编辑结果、属性和活动；原生内容草稿和结构化富文本，评论独立提交、订阅／回应／回复及可解开解决状态。 | 窄容器、内容／属性编辑独立、外部更新、权限、键盘、取消和焦点回归；不将远端写入作为本地功能。 |

## 验收结果

| 维度 | 实际覆盖与边界 |
| --- | --- |
| 状态与数据 | Chromium 实测 Attachment 取消、Bubble 反应、Marker 动态状态、Trace 展开、Issue Detail 属性与活动、评论和订阅。宿主拒绝富文本更新并同步另一字段时保留宿主数据。完整变体和控制模式组合未验。 |
| 表单、键盘与无障碍 | 实测 Questionnaire 原生 FormData、回退、跳过、重置、错误关联及聚焦；Issue Composer 无标题时聚焦错误、文件和连续创建、菜单键盘及退出归焦。Attachment 的预览与取消为相邻控制、不触发表单提交。Code Block 有命名的滚动区域与复制反馈。未用读屏。 |
| 国际化与触摸 | 模拟组合输入的 Enter 不推进问卷；附件与 Trace 的 Chromium 粗指针通过；五项消息原语在 320 px 深色 RTL 检查。未验真实 IME、实机或其他浏览器，未覆盖所有组件的 RTL。 |
| 生命周期和滚动 | Message Scroller 的 25 px 上轮露出、插入历史偏移不超过 1 px、读历史时增量不抢滚动，以及回到最新均在浏览器测量。流式代码只对新增内容更新，换行、18 起始行号和差异保留。未验大型转录或所有来回切换路径。 |
| SSR／hydration | Message Scroller 和 Questionnaire 原生 SSR 与 hydration 通过代表用例，其余未逐项验。 |
| 弹层与视觉 | Chromium 检查浅色宽屏、深色 320 px、附件与消息相邻、错误行和详情布局。Issue Detail 宽 1200 px 时属性栏 224 px、间距 48 px；窄屏编辑聚焦输入、页面横向溢出 0 px。未升级原目录的 Linear 对齐评级。 |
| 安全、隐私与性能 | Code Block 用文本节点显示源码，复制原串；Issue Detail 拒绝危险链接并用允许的节点渲染富文本。仅本地 File、示例会话和回调，无直接上传、真实会话或写入。性能未作大规模基准。 |
| 类型与分发 | 两套 SDK 的根和子路径、生产文档「使用组件」原生代码；外部消费者以本地 0.1.0 tarball 安装，验证 `.pnpm` 实际安装路径、类型和 Vite 生产构建。原 Svelte registry 与共享包入口不变。 |
