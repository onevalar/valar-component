# 注册表区块：Svelte → React / Vue

## 范围与来源

第 10–14 批。基线为 `cfd989c` 的 Valar `docs/src/lib/registry/blocks/` 及本次工作区的设计定制；`calendar-15` 的周数基线在本批补齐。仓库及上游来源见根目录 `LICENSE.md`、`upstream-source-manifest.json`；使用转换规范 1.0。目标为 React 19、Vue 3.5、Tailwind CSS 4，复用各端 SDK、Valar 语义 token 与原生交互原语；不引入第三个框架的运行时。以下验收不改变基础组件目录的 Linear 对齐等级。

- Svelte 仍默认，保持 `/view/<id>` 预览、同名 CLI registry 安装，以及既有共享包入口。Week Numbers 是原 Calendar 的可选显示，不改变其他默认示例。
- React / Vue 的 Markdown 安装清单分别链接 `/block-templates/<id>?framework=react` 与 `?framework=vue`，中文有 `/zh` 入口。五类模板从各自预览应用的 `src/blocks/` 加载并展示同源可复制代码；不把 78 个变体计入 SDK 的组件导出。源区块合同见[中文清单](../../docs/content/zh/installation/registry-blocks.md)；行为列描述 Svelte 源，而不是目标全部变体均通过对照的声明。
- 真实鉴权、远程项目数据、邮件及通知服务等由宿主实现。源区块没有对应 Linear 页面时，以实际 Svelte 来源比较布局、边界、相邻控件和浅深主题；不声明与 Linear 逐像素一致。

侧栏有意缩短静态文本与数据：01–06、14 和嵌套导航使用 17 个示例目的地；07–08 没有项目溢出列表；09 邮件使用 5 项；10 与 15 各有 2 个工作区及 2 个初始收藏；11 文件树有 11 个叶子节点；13 有 8 个设置分区。12 显示选中日期及日历总数，不提供事件编辑器。16 搜索本地导航而非远程索引。局部预览的菜单、导航、主题和外部控制只在当前预览生效；行内 Edit 不打开编辑表单，Delete 会删除该示例行。

日期差异：09 拒绝跨周末区间，失败后保留的起点因框架而异；14、20 在 React 标记为禁用、在 Vue 标记为不可选，均划线；26 清除因新入住日而无效的退房日；27 的图表提示和过渡由各端图表库处理；30、31 用 `Intl.DateTimeFormat.formatRange`，缩写或空白与 Svelte 可不同。20 和 31 的预约、添加事件不访问外部系统。

仪表板保留 91 个图表数据点，使用原生 SVG 替代 LayerChart；表格使用源 68 行中的 14 行，编辑抽屉不含源副图，三个其他视图仍为占位。组件展示以首字母替代远程头像，资料选择器简化为人员子菜单。付款、语音、附件、邀请、验证、邮件操作及 AI 任务均为演示，不对接服务。

## 环境与证据

- Linux orb，Node 24.22.2、pnpm 12.14.0。三浏览器代表检查使用 Chromium 157.0.8103.78、Firefox 153.0、Linux WebKit 26.5。认证 `otp-02` 的六位输入（含前导零）、RTL 页面下 OTP LTR、验证成功和无横向溢出，在两框架 × 三引擎通过；周数标题、侧栏、仪表板及组件展示均作代表挂载检查。
- Chromium CDP `Input.imeSetComposition` 检查两端 Tags Input：输入中的 Enter 不新建标签，提交候选「设计」仍只更新文本，下一次 Enter 才添加。此项不是 OS 输入法人工验证。
- 认证截图与交互记录：`blocks-auth-desktop.png`（React 浅色宽屏）、`blocks-otp-dark.png`（Vue 深色 320 px，输入三组数字后验证）、`blocks-auth-submit.mp4`（鼠标跨过相邻字段并提交，显示确认密码不匹配）。
- 侧栏 Chromium 回归挂载双框架共 58 个示例，1180 px 无横向溢出。深色中文 320 px 检查 288 px 右侧 Sheet 和 Escape 归焦，宽屏并列日历栏为 248 px、日历格宽 196 px；另检查外部控制、菜单、文件树、邮件与设置。复跑脚本 `sidebar-smoke.sh`，截屏 `sidebar-react-mail.png`、`sidebar-vue-dual.png`。
- 日历 Chromium 浅色英文 1000 px、深色中文 320 px 共验证 128 个初始渲染；检查了选择上限、禁用范围、中文相对日期、日期筛图与抽屉归焦。320 px 英文周数列发现题头与相邻星期逼近，改用可见 `Wk`、保留可访问名称 `Week`，复查浅深截图并留文字边界回归。Svelte 生产 `/view/calendar-15` 的独立回归确认 2025-12-29 所在行进入 ISO 第 1 周，上一行仍为第 52 周。
- 仪表板与组件展示在两端 Chromium 验证日期范围切换、图表键盘读数、抽屉修改状态、表格全选与显隐列、键盘换序和分页，以及结账校验/清空、滑杆、语音模式、提及和 Copilot 示例任务。两端以指针将 Cover page 拖到 Table of contents 之后。深色中文在 320 px 无页面横向溢出；移动宽度的抽屉关闭返回快速创建按钮。浅色 1440 px 仪表板核对四卡同排、图表和表格工具条；390 px 深色组件展示核对月份、年份和 CVV 不相碰。未逐项验证所有菜单分支及全状态视觉对照。
