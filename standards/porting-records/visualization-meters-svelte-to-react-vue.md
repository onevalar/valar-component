# 可视化与仪表：Svelte → React / Vue

2026-11-27 · 第 5 批 · 已通过代表场景及独立安装，React/Vue 各达 69/79 组。采用[转换规范 v1.0](../COMPONENT_PORTING.md)，以 Valar `cfd989c9f63156774dbfb3871cc1fa1774e62ee5` 的 `docs/src/lib/registry/ui/<slug>` 及相应的 RULES、文档和测试为源。保留 Svelte registry 不变。React 19.2.3／Vue 3.5.45、Tailwind 4.3.3、Node 24.22.2／pnpm 12.14.0。尚未独立审阅。

## 能力合同与验收计划

既有 Chart 提供通用带交互图表，既有 Slider 移动滑块；两者不替代这些组件各自的静态几何、Canvas 或固定指针。目标实现在各自框架渲染 SVG、HTML 或 Canvas，不将 Svelte 文档树作为消费者依赖。

| 组件 | 保留的行为与目标方式 | 用来发现不等价的验收输入 |
| --- | --- | --- |
| Donut Chart | 装饰性 SVG，固定分母；零值不造图形，空余不是额外类别，显示/隐藏系列不重新归一；由相邻图例提供确数。 | 删除非主系列后剩余弧度不变；全零／空容器，无键盘焦点。 |
| Gauge / GaugeArc | 只读 `meter`；弧度和 `aria-valuenow` 限幅，文字允许超量；`GaugeArc` 独立支持 `null` 虚线轨道，可用于同一 SVG 多环。 | `132%` 的图形与 `100%` 边界一致而文字仍为 `132%`；缺失与真实零可区分。 |
| Ruler Slider | 单值、固定指针与平移刻度；拖动、惯性、回弹及轮滚，减少动效保留输入和吸附；键盘、可访问读数、原生隐藏字段及提交回调。 | 非零 min + 非整步输入，读取步进与表单值；区分输入中、提交、取消与禁用；分别测有/无惯性，滚动旁路与归焦。 |
| Sparkline | 装饰性 SVG，不平滑数据；`null` 断开，零在基线，单点和末点保留，通过相邻文字提供可访问摘要。 | 对同一组非对称样本同时包含起点零、间隙、峰值和尾部零，确认非零数据坐标及不跨越间隙。 |
| Texture Fill | 装饰性百分比 Canvas，五种纹理、颜色 token 和图形限幅；DPR 有上界，监听尺寸、颜色和减少动效偏好并清理。 | 用同一容器对 0/非零/超界取样；切换主题、DPR/尺寸与减少动效，检查重绘和层级。 |
| Tick Meter | 只读 60 根 SVG 线；色调走 token，图形/数值限幅，文字保留超量；空值由宿主处理。 | 非零非半数值验证四舍五入，超界验证 60 根及原始文字，核对 accessible name/valueText。 |
| Waffle Chart | 非零合计恰好分配 100 格，最大余数；零/空不绘制；有名称、非交互，精确值由图例表达。 | 3 组非对称数据与并列余数，核对总数、类别、次序；切换零／空后无格。 |

来源授权按组件核对原有 `LICENSE.md` 与 `tick-meter/PROVENANCE.md`，在 SDK 随包说明中保留适用的版权和独立实现说明。不能把静态组件的装饰性语义移到进度条，也不新增来源没有的可交互工具提示。

## 验证范围

- 七项均适用值与边界、无障碍、双主题布局、公开类型和独立安装；在文档站复制正确入口。无 Portal。6 个只读组件不自行处理键盘、表单或 IME；输入法不适用于 Ruler Slider 的按键和拖动接口。
- Ruler Slider 另验输入状态、受控更新、提交、取消和捕获释放；Canvas 另验限定客户端副作用及卸载清理。SVG/HTML 与 Ruler 适用服务端初始输出、状态一致性和 hydration；Canvas 服务端保留容器框架，不在服务端绘图。
- 触摸、RTL、性能、读屏和跨浏览器按适用场景记实测或待验证。默认组件不联网、不执行 HTML、不读写剪贴板。

## 交付与实测结果

- 公开入口：`@valar/{react,vue}-ui/<slug>`、SDK 根导出与 `theme.css`；两端 preview 中的 14 个原生示例也是原文档站「使用组件」的可复制来源。没有增加运行时依赖，随包保留适用的 MIT 来源。原 Svelte registry 与共享 SDK 保留。
- 在 monorepo 工作区链接之外，以 `pnpm --ignore-workspace install` 安装两套 tarball，核对 `.pnpm` 的真实路径，两套独立消费者类型检查及生产构建均通过。`apps/framework-comparison/tests/visualization-meters.spec.ts` 的 14 项新增检查及已有 118 项回归在独立生产消费者与 Svelte 对照共通过 **132/132**。
- 同站生产构建通过，文档 `playwright.usage.config.ts` **17/17**，含两套 SDK 的各 7 个新增入口；`pnpm --filter docs check` 为 **0 错误、0 警告**。Cloudflare Pages adapter 仍报告路由排除规则超上限并裁减；未部署。
- 浅宽／深窄预览检查了相邻图例与控件、零点和缺失段、132% 文字与满刻度、固定分母及 56／22／22 格分配。Canvas 两主题稳定像素取样与缩放通过；五种纹理在 65%、DPR 2、减少动效下与 Svelte 像素相同。标尺尺寸、可访问值、键盘、触摸模拟与竖滚旁路、捕获取消、惯性、边界提交、SSR/hydration 均有代表场景证据；拖动至 6.75 后松开，并用 End 提交 11.25，指针保持居中。
- 仍待实机、读屏实测、跨浏览器、完整 RTL 与长时性能；这不改变原 Svelte 对齐等级。下一批为对话与业务组件。
