## 3. State and Integration Design

- Native wrappers retain forwarded props/emits, `$attrs`, slots and composition. Do not claim Svelte refs/snippets/callbacks are supported. Component refs refer to Vue component instances; no fake DOM-ref API.
- Reka `modelValue`/`open` and update emits are the controlled contract; `defaultValue`/`defaultOpen` seed uncontrolled usage. Running transitions between controlled/uncontrolled ownership are not promised.
- Input retains upstream passive useVModel. The fixture uses controlled state and a keyed remount on native form reset to restore passive and engine-local state/hidden inputs; this is an explicit demo reset strategy, not a new SDK auto-reset feature.
- Native Reka Slider's `name` serializes array values as `name[0]`, not a scalar name. The preview omits that prop and explicitly serializes controlled scalar `quota` via a hidden input, matching the parent-owned Svelte fixture's adapter rather than pretending the engines have the same form API.
- Calendar caption changes update placeholder only; selection is owned by Reka. Range partial selection, disabled dates and keyboard navigation stay in Reka. Month and year chooser popovers are independent native Reka popovers.
- Scalar keyboard uses a narrow as-child surface because Reka 2.10.5 SliderImpl handles modifiers unconditionally. Only scalar key handling is replaced; pointer/drag handlers and engine geometry remain native. Four arrows, default 2×step Page/Shift, Home/End and modifier arithmetic have unit coverage; actual bubbling and drag require parent browser verification.
- Follow-up measured contract from parent Chromium 147: Svelte's final End value is the largest permitted min-relative grid step, not its temporary intermediate max. Vue scalar key updates/commits now directly use that final grid value (-20/80/3 → 79); native multi-thumb handling is untouched. Regression cases include off-grid maxima, already-aligned maxima and fractional step division. Both calendar dropdown compositions already render month before year (11月, then 2026年); no slot/API reordering was needed. Preview now has an inline data favicon.
- Follow-up rendered review: Calendar and RangeCalendar navigation now use borderless ghost cell-size (36px) buttons, normal enabled opacity, centered 36px headers and 6px month/year caption gaps. RangeCalendar uses full-width absolute navigation like Calendar. Shared Calendar p-2 / RangeCalendar p-3 styles remain intact; native Reka engines/forwarded overrides are unchanged. SelectContent defaults to popper/start and retains its native translate-y-1 4px gap, with explicit position/align overrides still available.
- Bounded range-height investigation at 390px in Chromium 147.0.7727.15 reproduced Svelte section 428.1875px versus Vue 424.1875px. Both weekday heads were 19.1875px and bodies 264px; Svelte's actual range grid is flex-column with gap-1 (4px between head/body), while Vue retained an upstream table with space-x-1. RangeCalendarGrid now uses the source's flex-column/gap-1 layout; its existing parent wrapper still owns the 16px header/grid margin. No padding, fixtures, controls or engine/state logic changed.
- The preview now uses the actual pinned upstream ChartLineExample/PowerUsage native ChartTooltip + ChartCrosshair + componentToString(ChartTooltipContent, hideLabel:true) composition through SDK public exports. Tooltip payload retains 0, 9 and null; only the line's y accessor maps null to NaN. The SDK's zero-value fix shows 0 and suppresses null numeric text; hover acceptance remains parent-owned.
- No async business behavior, data requests, analytics or services are added. Engine lifecycle, portals and cleanup remain the dependencies' responsibility and require runtime checks.
