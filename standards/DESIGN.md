# Valar Svelte 组件设计规范

2026-11-11 · Linear 网页应用对齐计划与首批实测

Valar 应能用自己的组件复现 Linear 的典型界面。对齐范围包括浅深主题、文字、图标、密度、组件尺寸与搭配、键盘和指针状态，以及状态之间的动效。[组件对齐清单](LINEAR_ALIGNMENT.md)记录现有组件、组合缺口与进度。[中性色规范](NEUTRAL_COLOR_SPEC.md)保留 11 张参考截图中的 sRGB 色值和取样位置。

## 参考环境

2026-11-11 在用户已登录的 [Linear 网页应用](https://linear.app/)中操作。视口为 1042 × 853 CSS px，设备像素比为 2。测量覆盖 Agent、My issues、Preferences、新建 Issue、新建项目和帮助菜单。通过界面切换 Dark，并恢复 System preference。下文使用 CSS px；取样以可见控件的计算样式为准，部分状态从与目标元素匹配的 CSS 声明读取。

计算样式和截图各自保留。前者可区分透明边框、伪元素、控件本身与外部阴影。截图可核对叠加后的视觉结果，并补充桌面界面与其他尺寸的样本。两类证据对应不同窗口、组件实例和显示条件。

## 组件与组合

### 导航与按钮

- Agent 侧栏行高 28 px、圆角 8 px，内层左右内边距约为 8／9 px。普通行透明；选中底色 Light `lch(89.54% 0.5 282)`、Dark `lch(13.845% 1.3 272)`。文字颜色过渡 150 ms。
- My issues 的 Assigned、Created、Subscribed、Activity 是跨 URL 的链接胶囊。实测高度 28 px，左右内边距 10 px，文字 12 px / 500，圆角 `9999px`。应用内的面板切换继续使用 Valar Tabs 的 tablist、trigger 与 panel 语义；跨 URL 的视图切换使用可导航链接与当前页标记。
- 胶囊默认底色 Light `lch(99.997% 0.5 282)`、Dark `lch(10.149% 0.593 272)`；选中底色 Light `lch(93.483% 0.5 282)`、Dark `lch(16.706% 0.979 272)`。未选项的 `:hover` 与 `:active` 规则同色，Light `lch(94.854% 0.5 282)`、Dark `lch(14.006% 0.593 272)`。键盘焦点轮廓为 1 px 实线，颜色跟随主题强调色。
- 图标按钮与胶囊按钮均测到 150 ms 的边框、背景、文字和透明度过渡。未选胶囊在进入 hover 或 active 时把持续时间设为 0，退出回到基础过渡。按钮使用时在同一操作组突出主操作，其余按内容选择描边或无底。
- 项目表单的团队选择是真正 `disabled`。24 px 高、胶囊形、整体 `opacity: 0.6`。底色 Light `lch(100% 0 282)`、Dark `lch(13.861% 1.139 272)`。空白的新建 Issue 和项目表单中，提交按钮仍是可用控件。两种情况各自建例。

### My issues 列表

- 标题栏将页面标题与新建入口分列两侧。下一行将四个 28 px 高的视图胶囊放左侧，筛选、显示选项和详情按钮放右侧。三个图标按钮为 28 × 28 px，宽度不足时工具栏换行。
- 筛选从搜索字段开始，选字段后查找对应选项。应用筛选后在工具栏下方显示条件，条件由字段、比较关系、选值和移除动作组成，支持继续添加与清除。显示选项单独管理分组、排序和已完成问题的可见性。
- 有数据时将优先级图标、问题编号、状态和标题依次放在同一行。启用分组时用组头显示状态图标、组名和数量。点击行可显示详情，详情在窄屏下移到列表下方。行字段参考 Linear 官方截图，尺寸使用 Valar 预览值。[My issues](https://linear.app/docs/my-issues) · [Display options](https://linear.app/docs/display-options)
- 视图自身为空时显示居中的插图、对应视图的说明和新建入口。已有问题被筛选掉时显示无匹配结果，并提供重置操作。详情栏未选中问题时保留简短占位提示。
- 本地场景原型 `my-issues-01` 使用 Valar Tabs 在单页切换示例数据，筛选通过 Popover 与 Command 组合。创建、筛选和显示状态都在当前预览中生效。参考界面的高级筛选、看板及远程保存视图属于后续场景。

### 设置、表单与 Switch

- 设置卡片将标题或「标签＋说明」放左侧，将 Select、Switch 或行动按钮放右侧。Preferences 卡片实测圆角 10 px，行内可使用 16 px 内边距和 12 px 间距。独立设置项可用 Card、Field、Separator、对应控件组合。
- Preferences Select 实测高 30 px、圆角 8 px、文字 13 px，默认描边由伪元素阴影形成。深色用键盘移动到未选择项时，选项仍保持 `aria-selected=false`，高亮由圆角 8 px 的背景伪元素绘制，实测 `lch(25.69% 1.975 272)`。方向键移动高亮，Escape 返回触发器，触发器显示 1 px 焦点轮廓。
- Switch 常规轨道 30 × 20 px、滑块 14 × 14 px，水平端点内缩 3 px。新建 Issue 的紧凑 Switch 轨道约 22 × 14 px、滑块 10 × 10 px，端点内缩 2 px。设置页把说明与常规开关同行，弹窗底部用紧凑开关搭配短标签和主按钮。
- Switch 关闭轨道 Light `lch(82.484% 0.054 281.837)`、Dark `lch(47.551% 0.913 271.998)`；开启轨道使用主题强调色。轨道背景和透明度为 150 ms `ease-out`。滑块左右边各过渡 100 ms `ease-out`，其中一侧延迟 50 ms，切换方向时交换延迟。紧凑 Switch 的键盘焦点可见 1 px 强调色轮廓。

设置页布局取自本地场景原型 `settings-01`。桌面设置侧栏样本宽 204 px，左右各留 12 px，导航行高 28 px、圆角 8 px。设置内容列宽上限为 640 px。窄屏示例将导航置顶，并在设置列过窄时让控件移到说明下方。

设置下拉面板使用 12 px 圆角，选项高 32 px，上下留白各 4 px。实测示例宽 202 px。Light 表面 `lch(100% 0 282)`，Dark 表面 `lch(16.433% 1.3 272)`，两者的 0.5 px 外沿阴影分别为 `lch(86.5% 0 282)` 和 `lch(38.032% 2.38 272)`。选项高亮和已选分别由键盘焦点与当前值驱动。

### 菜单、Tooltip 与 Dialog

- 帮助菜单和工作区菜单实测圆角 12 px、描边 0.5 px、选项高度 32 px。菜单行图标与文字的内层间距 8 px。Light 工作区菜单底 `lch(100% 0 282)`、描边 `lch(91.9% 0 282)`。Dark 帮助菜单底 `lch(12.72% 0.85 272)`、描边 `lch(25.68% 1.93 272)`，阴影为 `0 3px 8px`、`0 2px 5px`、`0 1px 1px` 三层，均为 12.5% 黑。
- Tooltip 用于解释图标或缩短的标签。快捷键和正文并排，独立于按钮自身的选中状态。两主题的实测显示色见[中性色规范](NEUTRAL_COLOR_SPEC.md#浮层分隔线与阴影)。工作区样本的延迟、尺寸和状态见下方共用菜单与 Tooltip 记录。
- 新建 Issue 使用自动聚焦标题的 Dialog。窗体圆角 21 px，外层内边距 0.5 px，紧凑形态宽度约 750 px。标题与描述纵向排列，下方是元数据操作组，底部右侧紧凑 Switch 与主按钮同行。新建项目使用更大的编辑区域与 24 px 标题。两个创建流程都可通过关闭按钮或 Escape 退出空白表单。
- Issue Dialog 实测 Light 表面 `lch(100% 0 282)`、Dark 表面 `lch(9.232% 0.85 272)`。Light Issue 遮罩背景为 25% 黑；Dark Project 遮罩背景为 40% 黑。遮罩元素自身还有独立透明度，记录 CSS 背景和截图合成值时分别标明取样部位。
- Issue Dialog 展开和收起使用 `cubic-bezier(0.43, 0.07, 0.59, 0.94)`。外层 `max-width` 220 ms、背景 100 ms；表单最小高度 300 ms、背景和阴影 200 ms；Dialog 内边距 300 ms。已触发展开并观测到中间宽度。CSS 在 `prefers-reduced-motion: reduce` 下将窗体和外层过渡时长设为 0。开合弹窗本身的完整动画时序单独待测。

### 基础组件默认外观

- 全库的焦点提示画在组件边界内。表单优先改变现有边框颜色，其他控件可以用内描边、底色或下划线提示焦点。浏览器默认轮廓也向内收。键盘导航、选中和校验错误各自保留可见反馈。
- Card 使用 10 px 圆角、细描边及主题卡片底色。常规与小尺寸分别使用 16 px、12 px 留白；设置列表把卡片留白交给各行。边到边内容与底部操作区随卡片裁切。
- Input 以 Linear Profile 实页复测值为准。高 32 px、圆角 8 px、左右内边距 12 px、桌面正文 13 px／400。浅色底、边框、占位字为白色、`lch(86.5% 0 282)`、`lch(66% 1 282)`，深色为 `lch(9.232% .85 272)`、`lch(30.833% 1.93 272)`、`lch(39.452% 1.425 272)`。边框为 0.5 px，过渡 150 ms。聚焦边框分别为 `lch(78.5% 0 282)`、`lch(28.032% 6.93 272)`，同时即时显示蓝紫色 1 px 轮廓，偏移 −1 px。窄屏字号 16 px 和错误描边为 Valar 的通用规则，表单受限行目前只取样到文本和升级入口。
- Separator 的横向样本来自 Linear Preferences 的 Interface theme 卡片。行间线厚 0.5 px，浅色叠加黑色 8.8%，深色叠加白色 8.3%。640 px 卡片内的第二条线两端各内收 16 px。Valar 的通用横线与竖线采用同一粗细和叠加色。Inbox 分栏也实测到 0.5 px 竖线，该场景有独立的布局边界配色。
- Kbd 在 Linear 快捷键弹窗中为 21.1 px 高、最小宽 20 px、圆角 3 px、水平留白 4 px，字重 450。帮助菜单尾部的字符无描边和内边距，字重 500。Inbox「Show display options」工具提示的键帽高 17.1 px、最小宽 18 px、圆角 4 px、水平留白 2 px，字重 400。三种样式均为 11 px 字号、12.1 px 行高、3 px 按键间距。浅色字 `lch(40% 1 282)`，深色分别为 `lch(63.304% 1.425 272)`（标准）和 `lch(64.714% 1.425 272)`（菜单、提示）。带框键帽浅色描边 `lch(91.9% 0 282)`，深色标准键帽 `lch(16.793% 1.93 272)`、紧凑键帽 `lch(20.28% 1.93 272)`。
- Button 的 `icon-sm` 参考 Linear 工具栏，控件 28 × 28 px，默认图标 14 × 14 px。边框色、底色、文字色和透明度使用 150 ms 过渡，系统开启减少动态效果时即时切换。
- Select 使用 30 px / 28 px 高的常规 / 小触发器，默认主题圆角 8 px。选项面板圆角 12 px，选项行至少 32 px；键盘焦点、当前选值和错误状态分别表达。设置区域可覆盖 Select 的表面和高亮颜色。
- Switch 沿用上述常规与紧凑尺寸，默认使用白色滑块、灰色关闭轨道、紫色开启轨道与 1 px 键盘焦点描边。普通滑块平移，设置变体保留实测的两侧交错过渡。
- Dropdown Menu 和子菜单默认使用 12 px 圆角、6 px 面板留白及 32 px 最小行高；图文间距为 8 px。Popover 同样使用 12 px 圆角，内容默认留白 10 px。Select、菜单、Popover 与 Tooltip 共用实色浮层和主题描边、阴影；Popover 的面板留白是 Valar 的组合值。
- Tooltip 默认无箭头和开合动效。圆角 8 px，横向和纵向留白分别为 8 px 和 5 px，与触发器相隔 6 px。Inbox 的显示选项提示在锚点下方，底栏的聊天历史提示在锚点上方并向内避开右边缘。Provider 默认延迟 500 ms。Valar 保留键盘聚焦立即显示及 Escape 关闭，便于无鼠标使用。
- 开关和浮层遵循系统的减少动态效果设置。用基础组件页检验默认用法，用工作区场景页检验组合样式。

#### 按钮、选择与页内切换复测

2026-11-13 在 Linear 的 Teams、Preferences、Issue labels、新建 Issue／Project 和 Projects 时间线复测浅深主题。设置主题、选中的标签行和空白草稿均恢复到取样前状态。

- **Button。** Teams 的 Create new team 和 Export CSV 高 32 px，胶囊圆角，水平留白 12 px，13 px／500。新建 Issue 的主操作高 28 px，水平留白 10 px、12 px／500。主操作浅色默认和悬停为 `lch(53% 52.26 286.91)`、`lch(47% 50.26 286.91)`，深色为 `lch(47.918% 59.303 288.421)`、`lch(52.418% 61.103 288.421)`。次操作浅色底及悬停 `lch(99.997% .5 282)`、`lch(95.883% .157 282)`，深色默认 `lch(10.149% .689 272)`。描边由 0.5 px 边缘阴影形成。Customize sidebar 默认透明；Set team 禁用态高 24 px。Valar 将胶囊作为所有独立文字按钮的默认形状。同尺寸的主按钮、次要、描边、幽灵、危险和链接共用形状规则。图标按钮使用主题圆角，按钮组控制相连边角。焦点为内描边，待提交状态通过 `loading` 保留焦点并阻止重复提交。
- **Checkbox。** Issue labels 复选框浅深均 14 × 14 px、1 px 边框、3 px 圆角，勾选图形约 10 × 9 px。未选底透明，边缘浅色 `lch(52.04% 0 282)`、深色 `lch(48.72% 1.48 272)`。选中底为当主题强调色。Space 选中独立行，批量工具区显示计数，可清除选择。Valar 表头的部分选中用同底色短横线，保留可见内侧焦点、原生表单值和关联错误。

## 实施与验收

完成以整个基础组件为单位。先对照 Linear 实页列出该组件的对应场景和状态，再检查 Valar 的普通调用、各相关变体、状态切换和场景搭配。每项适用状态都要有对应实现和验收证据。对于 Linear 中找不到直接对应的 Valar 用法，记录实页检查范围和 Valar 的设计处理。单个状态或场景通过时，记录为部分对齐。

每个组件的对齐记录应能回答以下问题。

1. **在哪里使用。** 写明 Linear 页面、触发入口、主题、尺寸与用途。指出使用场景和相邻组件、顺序、容器内边距、行列间距、窄屏布局。
2. **有哪些状态。** 逐项核对适用的默认、悬停、按下、键盘焦点、选中、展开、禁用、只读、加载、空、错误与长文本。描述颜色、边框、阴影、尺寸、字体、图标、动画属性与时长。记录实测、CSS 声明与设计决策的来源。
3. **用哪个 Valar 入口。** 优先修改已有组件，说明复用方式和需要的变体。组合缺口先用现有组件做最小可用示例。确实缺失的原语按其完整能力新增。Valar 独有组件继承相同的表面、边框、文字、图标、密度和交互反馈。
4. **如何验证。** 在 docs 示例、生成后的 registry 和共享包检查同一组件。用浅色、深色及实际组合页面检查尺寸、布局和状态；交互组件再核对焦点、键盘、触屏和减少动态效果。匹配不到的状态保留为待测，存在差异时记录原因和接受范围。

基础组件页的「默认」示例使用组件的实际默认参数。场景变体以用途命名，例如「项目日期」或「成员资料卡」。同一用途、同一尺寸的视觉变体共用尺寸和圆角规则，组件页、注册表与共享包从同一份源码验证。 组合内的控件应继承自身尺寸档位。父组件负责布局和留白，只有在文字需要换行时才允许高度随内容增长。带图标、选中标记或行尾操作的控件，用起止侧留白预留对应空间，并在窄屏和从右到左布局中检查。

### 布局验收

1. 替换内部控件或改动尺寸时，一并查看父容器的宽度、内边距、相邻控件及绝对定位元素。按组件规范或实页取样确定最小间距，记录实际值。Calendar 年月按钮与箭头的最小间距为 8 px，其他组件按各自场景确定。
2. 在基础组件页和受影响的实际组合里打开默认和相关变体。检查桌面、支持的最窄尺寸和发生布局切换的宽度。用长标签及真实语言检查裁切。分别查看浅深色和适用的悬停、键盘聚焦、展开状态。
3. 在浏览器量相邻边界，确认控件没有相互覆盖，实际点击命中正确元素。检查标题和内容的对齐、长文字的处理、浮层边界与内部滚动。页面横向无溢出只覆盖页面边界，内部间距需要单独验证。
4. 把已复现的重叠、裁切或点击遮挡写成浏览器回归断言。记录验证过的变体、宽度、状态和结果。影响范围内尚未通过的场景留在进度清单，待验收后再恢复目录入口。

可先用三种组合检验整体一致性。设置页验证侧栏、表单行、卡片和输入控件；My issues 验证胶囊导航、筛选、工具栏、列表和空状态；新建 Issue 验证弹窗、图标按钮、输入、元数据菜单和表单动作。组合的间距从对应 Linear 页面逐项记录。

- 优先筛选在「显示选项」中配置。任一通知来源或问题优先级匹配时，通知归入「优先」，其余归入「其他」。默认规则为分配、提及以及紧急／高／中优先级，提供恢复默认入口。配置和未读计数随当前预览更新。Linear 支持选择来源或创建筛选，Valar 用上述规则展示此行为。[Linear Priority inbox](https://linear.app/changelog/2026-09-03-priority-inbox)
- 列表行支持 J/K 或方向键移动焦点。详情用同样的键或上一条／下一条按钮切换，打开时标为已读。列表行和详情标题支持 U 切换已读、Alt+U 全部标为已读、H 打开暂缓菜单，以及 Backspace 删除当前通知、Shift+Backspace 删除已读通知。编辑区和浮层保留各自的键盘行为。[Linear Inbox](https://linear.app/docs/inbox)
- 暂缓提供 1 小时、1 天和 1 周预设。隐藏已暂缓通知时，暂缓后返回列表，到期后恢复原来的已读状态并重新出现。开启「显示已暂缓」后可以在详情中取消暂缓。
- 浅色和选中、悬停、焦点颜色沿用 Valar 的中性色分层，深色空界面参考登录实测。带数据的详情和窄屏详情使用 Valar 示例。右键菜单、自定义暂缓日期、宿主持久化和真实通知验证仍待覆盖。

### Agent 对话

- 登录实测使用 1403 × 984 px 深色视口。对话顶栏 44 px 高，标题切换胶囊 28 px 高。新对话输入区宽约 714 px、高约 106 px，左右内边距约 18 px。输入文字 15 px、行高 24 px。加号和发送键均为 24 × 24 px，间距 8 px。发送按钮用强调色，回复为空时按钮变灰。浅色依据此前同一界面的取样，Valar 以局部语义 token 表达输入表面、边框、文字与强调色。
- 空态在输入框下方显示三张示例卡片，卡片高约 134 px，间距约 8 px。图标在左上，标题与说明靠底。点击直接发送示例并切换到对应会话。下方列出最近对话，标题下拉支持搜索并提供新对话入口。[Linear Agent](https://linear.app/docs/linear-agent)
- 会话内容列宽约 824 px，用户消息在右侧有底气泡，助手正文在左侧无底。回复输入框宽约 824 px、高约 129 px，固定在消息区域下方。Enter 发送，Shift+Enter 换行。收到消息后先显示思考中，发送键切换为停止键，正文按段逐步出现。只读搜索完成后，折叠摘要显示用时，展开可查看搜索步骤。点击停止后发送键恢复。长回复保留阅读位置，点击「Latest」可跳到末尾。
- 加号菜单提供文件入口。使用合成文件实测到上传中和完成，文件行在输入框内，显示文件图标、文件名和大小。Valar 用 Attachment 组合表现准备中、可发送、超限和已发送，支持选择、拖入输入区、粘贴、移除和下载。单文件上限 10 MB，文件与回复存在当前页面。模拟的工具步骤只展示状态和结果摘要。
- 参考在 480 px 视口仍保留三列卡片，卡片文字会频繁换行。Valar 在容器宽度不足 525 px 时将卡片改为单列，并保留独立滚动的消息区和底部输入框。减少动态效果时禁用工作记录展开动效，跳到最新消息时立即定位。真实 Skill、外部集成、写入型工具和原站会话管理需要另行验证。

### 共用菜单、Tooltip 与图标

- 登录后在 Projects、Inbox、新建 Issue 和 Agent 核对工具栏与菜单。Projects 筛选和 Agent 附件菜单的深色表面为 `lch(12.72% 0.85 272)`，描边为 `lch(25.68% 1.93 272)`，圆角 12 px，描边 0.5 px，菜单行高 32 px、文字 13 px。浅色 Tooltip 底色为白色，描边为 `lch(91.9% 0 282)`，文字为 `lch(20% 1 282)`。
- Tooltip 实测圆角 8 px、内边距 5 × 8 px，文字和键帽间距 8 px。Projects 筛选冷悬停从移动鼠标到观察到提示约 571 ms，包含浏览器轮询时间。Valar 的工作区 Provider 设为 500 ms，提示与锚点间隔 6 px，碰撞内边距 8 px。工具栏提示优先向下，Agent 输入栏提示优先向上。参考样本在减少动态效果模式下也未显示 CSS 动画。Valar 的 surface 外观以即时显示和关闭为准。
- Projects 和 Inbox 的工具栏按钮为 28 × 28 px，图标为 14 × 14 px。未读按钮实测在深色选中时使用 `lch(18.634% 1.075 272)` 底色和白色图标，并通过 `aria-pressed` 表达状态。Issue 关闭按钮为 32 × 32 px，Agent 输入按钮为 24 × 24 px。Valar 继续用可配置图标库映射语义，原站填充轮廓与 Valar 图标几何仍有差异。
- 有筛选搜索、分层选项或多种控件的浮层使用 Popover，单次执行的菜单使用 Dropdown Menu。两者可以选择 `appearance="surface"`，与 Tooltip 的 surface 共用描边、颜色和阴影。Projects 工具栏和 Inbox 列表内的 F 打开筛选，Shift+V 打开显示选项。Agent 文件快捷键在输入区生效，Issue 属性菜单支持数字直选。文本输入、输入法组合和浏览器组合键保留各自行为。
- 参考 Inbox 当时无通知，空状态只显示设置入口。Valar 的通知批量、暂缓及禁用菜单项使用示例数据测试。参考窄视口的工作区有最小宽度，Valar 在自身 375 px 预览独立验证浮层边界。

### Issue 活动与评论

- 在 1403 × 984 px 的 Linear 浏览器实测。活动位于标题和描述下方，与属性栏并列。活动标题 15 px／23 px，标题行高 32 px。创建记录用小头像、动作和时间。没有评论时，创建记录下方直接显示新评论框。
- 评论与回复共用 8 px 圆角卡片，回复分行并用描边分隔。评论正文 15 px／24 px，作者和时间同行。回复正文与作者对齐。主评论框实测约 83 px 高，内边距 12 × 16 px，圆角 8 px，深色表面 `lch(9.232% 0.85 272)`，描边 `lch(16.793% 1.93 272)`，发送键为 24 × 24 px。
- 实测发布后出现线程回复框，评论菜单的 Edit 打开内联草稿，取消脏草稿弹出确认，保存后出现已编辑标记。按 Cmd+Enter 可发表线程回复。Valar 同时支持 Ctrl+Enter 和 Escape 取消，空草稿禁用发送，作者才能编辑自己的评论和回复。[Linear 评论与回复](https://linear.app/docs/comment-on-issues)
- Valar 在 My issues 和 Inbox 共用同一个活动区，按问题 ID 保留当前预览会话的评论与属性变更。参考窄屏样本仍受桌面工作区最小宽度限制，Valar 在窄容器把活动区放到属性和描述下方。预览将本地属性更新写入时间线，评论的附件保留本地文件名和 File 对象。订阅、表情回应与线程解决见下节，服务端协作留待接入真实业务。


### Issue 订阅、回应与线程解决

- 在 Linear 的合成 Issue 实测自己的订阅切换和订阅者选择器。活动标题与 28 px 高的操作区同行，订阅状态用文字表达，约 18 px 的订阅者头像在右侧。选择器打开后聚焦搜索，已订阅成员显示勾选。Valar 的预览中，新建问题会订阅当前用户，My issues 的订阅列表按当前用户的实际订阅状态筛选。[Linear 通知](https://linear.app/docs/notifications)
- 问题描述下、评论及回复各有回应入口。实测深色选择器宽约 272 px，搜索放在顶部，常用表情按八列排列。选择后在正文下显示表情和数量，再点可取消自己的回应。Valar 支持搜索常用表情、粘贴单个 Unicode 表情和方向键浏览，并在最后一个回应被移除时恢复到添加入口。[Linear 评论与回应](https://linear.app/docs/comment-on-issues)
- 解决线程后，约 44 px 高的摘要保留条数和作者，展开可查看原正文、回复与回应。Valar 可从回复菜单将该回复作为结论，折叠时显示一行摘要。重新打开线程恢复回复入口。已解决线程展开后提交新回复，Valar 的本地状态帮助函数会重新打开该线程。键盘操作后焦点回到摘要或评论菜单。
- 订阅、回应与解决状态由宿主按问题 ID 管理，My issues 和 Inbox 都使用共享 Issue Detail。预览状态保存在各自的页面会话。线程级订阅、工作区自定义表情和通知投递由后续业务接入提供。
