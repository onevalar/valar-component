# Valar Svelte 浅色与深色中性色规范

2026-11-11 · v1 · 截图取样与设计记录

本规范记录 Valar Svelte 后续配色定制所参考的黑、白、灰及轻微偏冷的灰色。表中的 HEX 是用户提供的 Linear 截图所呈现的颜色。当前组件样式仍使用仓库中的主题配置。

## 取样口径

- 从原始 CleanShot PNG 读取像素，按嵌入的 Display P3 色彩配置转换为 sRGB。纯色表面取平坦区域的主色，文字和图标取笔画内部的主色，描边取平直边缘。位置相关的像素以「约」或范围标记。
- 渐变停点按截图高度取样。边缘阴影和遮罩记录合成后的像素值，源样式的透明度、色标位置和模糊半径待确认。
- 表中的「待取样」表示对应主题或状态缺少可比画面。胶囊切换的选中和悬停按画面判断，状态名称保留参考控件的上下文。相同颜色可以复用，组件状态仍按各自用途记录。

## 使用与验收

- 主题落地时，按用途映射到 [现有语义变量](../docs/content/zh/theming.md)，再核对实际使用背景上的前景对比度、聚焦可见性和禁用状态。占位文字、降低强调的表单行与真正禁用的控件各自核对。
- 表中记录的浅色禁用按钮与深色降低强调行属于不同场景。待补的中性状态还包括普通按钮按下、部分组件的键盘聚焦与深色悬停、开关关闭轨道及其他未出现的选择控件状态。
- 品牌强调色、成功／警告／错误／信息和图表系列色另行设计。本规范的背景、分隔线和文字色可用于后续图表界面校准。
